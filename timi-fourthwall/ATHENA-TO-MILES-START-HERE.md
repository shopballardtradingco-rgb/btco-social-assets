## The five-stage modern workflow
1. **Listen:** create a short customer-interest survey with the approved concept images; do not pretend the survey is a live store. Use the included `SURVEY-READY-TO-BUILD.md`. Free Google Forms is suggested; attach three reference images and separately label the missing approved Sunshine variants as pending images.
2. **Own:** Timi personally creates the Fourthwall account with an email she controls and accepts agreements. Owner adds tax/identity/bank information privately through Fourthwall/Stripe Connect; never request these in chat. Set up shop name, handle, and homepage draft. No public launch.
3. **Design:** build privately visible draft products and a collection for each of the three themes. Obtain official artwork templates; create independent transparent print files WITHOUT altering designs. Fourthwall designer, Canva Free, and Photopea Free are optional helpers, not requirements.
4. **Sample:** show front/back previews, actual provider SKUs, variant/size, costs, extra printing, checkout shipping/tax, and exact total for owner approval BEFORE ordering. Then inspect actual product quality and fit when it arrives.
5. **Open:** confirm checkout, payouts, contact route, actual shipping estimates and return policy. Test safe checkout flow, with an explicitly approved paid test if needed. Only then make selected products public.
